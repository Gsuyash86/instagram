To Run the application Test Cases 

    npm test

To Run the application

    npm run start

StoryPreview Component:

Displays a selected user's story.
Shows a progress bar for each story with navigation through multiple stories.
Takes userStory and onClose as props.
Handles story progression and closing of the story view.
StoryList Component:

Displays a list of users stories.
Marks stories as "seen" when clicked.
Updates the seen status of stories in the state.
Opens the StoryPreview for the selected story.
Uses CSS for styling and handles user interactions.
